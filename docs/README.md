# Tài liệu dự án FoodVision AI

Mục lục tài liệu kỹ thuật và thiết kế của dự án **FoodVision AI**:

- 📁 **[01-requirements](./01-requirements/)**: Đặc tả yêu cầu phần mềm (SRS), Use Case, User Stories.
- 📁 **[02-architecture](./02-architecture/)**: Kiến trúc hệ thống (System Architecture), Sơ đồ thực thể liên kết (ERD), Từ điển dữ liệu (Data Dictionary).
- 📁 **[03-api](./03-api/)**: Đặc tả API (API Specification) và tài liệu OpenAPI.
- 📁 **[04-ai-model](./04-ai-model/)**: Tài liệu mô hình YOLO, bộ nhãn, tập dữ liệu huấn luyện và kết quả đánh giá.
- 📁 **[05-recommendation](./05-recommendation/)**: Thuật toán gợi ý món ăn và công thức tính điểm.
- 📁 **[06-testing](./06-testing/)**: Kế hoạch kiểm thử (Test Plan), kịch bản kiểm thử (Test Cases) và tiêu chí nghiệm thu.
- 📁 **[07-decisions](./07-decisions/)**: Hồ sơ quyết định kiến trúc (Architecture Decision Records - ADR).
- 📁 **[assets](./assets/)**: Hình ảnh, sơ đồ và các tài nguyên phục vụ tài liệu.
